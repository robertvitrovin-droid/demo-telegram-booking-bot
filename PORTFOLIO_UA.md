# Telegram-бот запису на послуги з адмін-панеллю (демо-проєкт)

**Демо-проєкт для портфоліо.** Зроблений для демонстрації навичок, не на замовлення клієнта. Салон, послуги й ціни умовні.

**Задача.** Невеликому сервісному бізнесу (барбершоп, салон, майстер, консультант) потрібен запис клієнтів без дзвінків і переписок: щоб людина сама бачила вільний час, а власник мав список записів під рукою.

**Рішення.**
- Сценарій у 4 кроки на inline-кнопках: послуга → дата → вільний слот → підтвердження, з кнопкою «Назад» на кожному кроці.
- Слоти рахуються з урахуванням тривалості послуги, робочих годин, вихідних і вже зайнятого часу; минулий час не показується.
- Захист від подвійного запису: два клієнти не можуть взяти один слот навіть одночасно.
- Автоматичне нагадування клієнту за 2 години (налаштовується).
- `/admin` лише для власника: список записів, скасування однією кнопкою, вивантаження всіх записів у CSV для Excel.
- Дані в SQLite, без платних сервісів; запуск однією командою.

**Стек.** Python 3, aiogram 3, asyncio, SQLite, pytest.

**Результат.** Робочий бот із покритою тестами логікою слотів (8 тестів), демо-режимом без токена, де справжні обробники проганяються через імітацію Telegram API, і скриншотами повного сценарію клієнта та адміністратора. Можна адаптувати під свої послуги, графік і мову за 1–2 дні.

**Ціна від:** 5 000 грн · термін від 3 днів
